# FrontDeskControl Web

Sanitized static web release of the FrontDeskControl workstation.

- No guest lists, reservation exports, payment data, databases, or backups are stored in this repository.
- PDFs selected inside the application are processed locally in the user's browser.
- Working data is stored only in that browser's local storage and does not synchronize between devices.
- The public site contains only the empty application; each browser starts with its own local workspace.
